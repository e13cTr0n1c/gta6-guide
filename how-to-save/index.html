How to save in GTA 6

I press Start or Options, choose Game, pick one of 15 slots and select Save Game. There is also one autosave slot, but I cannot save during a mission, and using a cheat stops saving for that session.

Last checked: 20 November 2026

The save menu

Manual save: Start/Options > Game > choose slot > Save Game. 15 manual slots plus one autosave slot (after missions, Wasted/Busted, major events). Can't save during missions. No mission replay. No in-game quit option.

  • GamesRadar+ (2026-11-19 (last updated))

What blocks a save

Using any cheat disables saving for that session.

  • GamesRadar+ (2026-11-19 (last updated))
  • GameSpot (18 November 2026)

If I mess up during a mission

This is not a save. It is how I undo a mistake while a mission is still running.

During missions use 'retry checkpoint' from the pause menu to undo mistakes.

  • The Guardian (Keza MacDonald) (19 November 2026)
