Which GTA 6 planning tools does this guide include?

I only built tools where the fact file has real figures. There is a garage cost planner, a money planner that stays in ranges, and a cheat finder. I do not offer a vehicle price lookup or a weapon price lookup.

Last checked: 20 November 2026

What I will not build

The fact file is blunt about the two lookups people usually want. I am quoting that, and I have not added a form that pretends otherwise.

  • Vehicle price lookup. NOT supportable honestly: no reputable per-model price list exists; registration costs show in game via WAiNK. Could become a reader-submitted tool later, clearly labelled.
  • Weapon/Ammu-Nation price lookup. NOT supportable: only fan wikis list prices.

Weapon prices: not found in the reputable outlets checked (only in fan wikis).

I could not find this in a reputable outlet.
